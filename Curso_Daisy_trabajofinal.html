1. Variables y Tipos de Datos

Las variables son contenedores para almacenar valores de datos. En Python no necesitas declarar el tipo de variable, ¡se detecta automáticamente!

# Esto es un comentario. Así se guardan los datos:
nombre = "Carlos"      # Tipo Texto (String)
edad = 25               # Tipo Entero (Integer)
precio = 19.99          # Tipo Decimal (Float)
es_mayor = True         # Tipo Booleano (Boolean)

print(nombre)           # Muestra "Carlos" en pantalla

2. Estructuras Condicionales (If / Else)

Permiten al programa tomar decisiones basadas en condiciones. **Ojo:** En Python es obligatorio usar la sangría (indentación) para saber qué código va dentro de la condición.

edad = 18

if edad >= 18:
    print("Eres mayor de edad.")
elif edad == 17:
    print("Casi eres mayor de edad.")
else:
    print("Eres menor de edad.")

3. Bucles (For / While)

Sirven para repetir un bloque de código varias veces sin tener que escribirlo de nuevo.

# Bucle FOR: Repite un número fijo de veces (aquí del 0 al 4)
for i in range(5):
    print("Número:", i)

# Bucle WHILE: Se repite mientras la condición sea verdadera
contador = 0
while contador < 3:
    print("Contando...")
    contador = contador + 1

4. Listas (Colecciones de datos)

Las listas permiten guardar múltiples elementos en una sola variable. Los elementos se cuentan empezando desde la posición **0**.

frutas = ["manzana", "banana", "cereza"]

# Acceder al primer elemento
print(frutas[0])  # Resultado: manzana

# Añadir un elemento nuevo
frutas.append("naranja")

5. Funciones

Una función es un bloque de código reutilizable que sólo se ejecuta cuando lo llamas. Se define con la palabra clave def.

def saludar(nombre_usuario):
    return "¡Hola " + nombre_usuario + ", bienvenido al curso!"

# Llamando a la función
mensaje = saludar("Ana")
print(mensaje)  # Resultado: ¡Hola Ana, bienvenido al curso!
