# MINI CURSO DE PYTHON ESENCIAL - ARCHIVO DE INFORMACIÓN ## DESCRIPCIÓN GENERAL Este proyecto es una guía interactiva y visual desarrollada en HTML5 y CSS3. Su objetivo es introducir a los estudiantes en el mundo de la programación utilizando Python, el lenguaje más popular del mundo. El curso se enfoca en la simplicidad, rompiendo conceptos complejos en explicaciones directas con ejemplos de código listos para probar, utilizando un diseño limpio, moderno y responsivo con una paleta de colores inspirada en la identidad oficial de Python. ## CONTENIDO DEL CURSO (LOS 5 PILARES DE PYTHON) El mini curso está estructurado en 5 módulos clave que constituyen las bases fundamentales de cualquier lenguaje de programación, aplicados directamente a la sintaxis de Python: Módulo 1: Variables y Tipos de Datos - Qué es una variable y cómo almacena la información. - El tipado dinámico en Python (no requiere declaración explícita). - Tipos de datos primarios: Texto (String), Enteros (Integer), Decimales (Float) y Booleanos. - Uso de la función nativa `print()`. Módulo 2: Estructuras Condicionales (If / Else) - Introducción a la toma de decisiones en el software. - Explicación de la sintaxis condicional: `if`, `elif` y `else`. - La importancia crítica de la sangría (indentación) en Python como parte estructural del código. Módulo 3: Bucles (For / While) - Automatización y repetición de tareas sin duplicar código. - Bucle `for` con el uso de la función `range()`. - Bucle `while` basado en evaluaciones condicionales de verdad. Módulo 4: Listas (Colecciones de Datos) - Concepto de estructuras de datos y colecciones para almacenamiento múltiple. - Indexación basada en cero (cómo se empiezan a contar los elementos desde 0). - Métodos básicos de manipulación (uso de `.append()`). Módulo 5: Funciones - Concepto de bloques de código reutilizables y modularización. - Sintaxis de definición mediante la palabra clave `def`. - Declaración de parámetros de entrada y retorno de resultados con `return`. ## REQUISITOS DEL SISTEMA Para ejecutar, visualizar o modificar el curso no se necesita ningún software costoso ni servidores externos. Solo requieres: - Un editor de texto moderno (Recomendado: Visual Studio Code). - Un navegador web actual (Google Chrome, Mozilla Firefox, Microsoft Edge, Safari). ## GUÍA DE INSTALACIÓN Y DESPLIEGUE EN VISUAL STUDIO CODE Sigue estos pasos detallados para poner en marcha el curso en tu entorno local: Paso 1: Abrir el Editor - Inicia Visual Studio Code en tu computadora. Paso 2: Crear el Archivo - En el menú superior, ve a 'Archivo' -> 'Nuevo archivo' (o presiona Ctrl + N en Windows/Linux, Cmd + N en Mac). - Selecciona el tipo de archivo como HTML o guárdalo directamente. Paso 3: Pegar el Código - Copia el código fuente HTML provisto previamente en este curso. - Pégalo dentro del archivo en blanco en Visual Studio Code. Paso 4: Guardar de Forma Correcta - Ve a 'Archivo' -> 'Guardar como...' (o presiona Ctrl + S / Cmd + S). - Nombra el archivo exactamente como `curso_python.html` (Asegúrate de que no termine en `.html.txt`). - Elige una ubicación fácil de recordar, como tu Escritorio o una carpeta de Proyectos. Paso 5: Visualizar en el Navegador - Método A (Fácil): Ve a la carpeta donde guardaste el archivo y haz doble clic sobre él. Se abrirá automáticamente en tu navegador predeterminado. - Método B (Arrastrar): Abre tu navegador web y arrastra el archivo `curso_python.html` desde tu explorador de archivos directamente al centro de la ventana del navegador. - Método C (Profesional): Si tienes instalada la extensión "Live Server" en VS Code, haz clic derecho dentro del código fuente y selecciona "Open with Live Server". Esto refrescará la página automáticamente cada vez que hagas cambios.
